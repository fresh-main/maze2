# Фракции

Оператор сервера выдаёт обычные фракции игроку командой `/fraction set <игрок> <FARMER|COOK|MEDIC|GLIDER|SCIENTIST|SURVIVOR|SOLDIER>`.
Предатель сохраняет отдельную команду `/fraction traitor <игрок> [маскировка]`. Удаление: `/fraction remove <игрок>`.
F3+F6 доступно оператору сервера только для выдачи себе фракции `OPERATOR`.

Старые `RUNNER` и `BUTCHER` оставлены с прежними числовыми ID ради совместимости сохранений, но новой командой не выдаются.

## Правила крафта

`labyrinthmod/craft_restrictions.json` автоматически создаётся при первом запуске сервера из шаблона, встроенного в мод, и загружается при каждом запуске. Файл лежит рядом с папкой мира и действует во всех мирах сервера. При обновлении мода существующий файл сохраняется без изменений. Ключ — ID предмета результата, значение — фракции, которым он запрещён:

```json
{
  "minecraft:compass": ["FARMER", "COOK"]
}
```

`labyrinthmod/fraction_recipes.json` также автоматически создаётся при первом запуске. Сейчас он пустой, так как рецепты бинтов ещё не выбраны. Для двух разных рецептов с одним результатом ключом будет ID рецепта, а значением — фракции, которым он разрешён. Неуказанные рецепты доступны всем:

```json
{
  "labyrinthmod:easy_bandage": ["MEDIC"]
}
```

ID упрощённого бинта приведён для примера; рецепт будет добавлен после выбора ингредиентов. Пластырь, морфин и бинт First Aid разрешено крафтить только медику. Начальные запреты автоматически добавляются и в уже существующий JSON, если этих предметов там ещё нет. Доступ к котлу Farmer's Delight проверяется отдельно по фракции повара и не является правилом крафта.

Крафт личной карты разрешён только выжившему. При ранении головы First Aid выживший с вероятностью 5% теряет прогресс карты, которую носит в инвентаре.
